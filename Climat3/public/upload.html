Upload Data

Follow the steps below to upload data:

  • Run 'npm run build' to rebuild the src/index.js file.
  • Move main.js from /dist to /public/js, overwriting the previous one.
  • Then cd into the public folder and run 'http-server -c-1' to see changes on localhost.
  • To push to the main website, from the base folder run 'firebase deploy'.
